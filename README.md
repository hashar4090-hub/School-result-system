# Student Result Card System

A simple school result project built with **HTML, CSS and jQuery**.

## Features
- Enter student marks and generate a printable result card
- Class ranking by percentage (1st, 2nd ... 30th and more; equal % = same position)
- Pass / Fail, grades, class topper
- Same names are allowed - students are identified by **Roll no.** (same roll no. in same class updates the old record)
- Data saved in the browser (localStorage); Backup / Restore (JSON) to move data to another phone
- Mobile friendly (app-style tabs)

## Structure
```
student-result-system/
├── index.html        page structure
├── css/style.css     all styling
├── js/app.js         all logic (jQuery)
└── js/vendor/jquery.min.js   jQuery 3 (works offline)
```

## How to run
Open `index.html` in Chrome/Safari. No server or internet needed.

## Put it online (get a link)
Upload the whole folder to Netlify Drop, GitHub Pages or Cloudflare Pages.
